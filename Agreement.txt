ABOUT THIS SOFTWARE
Video Compressor is a small hobby project. It was vibe-coded (written with the help of AI) as a PowerShell script that provides a simple window for compressing a video to a target file size. The actual video processing is done by FFmpeg (ffmpeg.exe and ffprobe.exe), a separate open-source program that is bundled with this installer.
